# end-to-end-sales-and-marketing-dashboard
This project showcases interactive and insightful Power BI dashboards built using the Marketing Campaign Dataset and the Superstore Dataset. These dashboards provide business intelligence through KPIs, visual analytics, and advanced techniques like RFM segmentation and forecasting.
Project Highlights

Marketing Campaign Dashboard
Data Source: Marketing Campaign Dataset
Key Pages & Visuals:
Customer Overview
KPI Cards: Total Customers, Average Income, Total Responses, Avg. Recency
Charts: Donut (Marital Status), Bar (Age Groups), Treemap (Income by Education)
Extras: Line chart for signup trends, Income histogram, Box Plot for Age vs. Income

Purchasing Behavior
KPI Cards: Average Monthly Spend, Total Spend, Top Product Category
Visuals: Stacked Bar (Spend by Category), Heatmap (Channels vs. Recency)
Advanced: RFM Segmentation (Clustered using DAX)
Campaign Performance

KPIs: Campaign Response Rate, Top Campaign, Revenue from Responders
Visuals: Campaign Funnel, Acceptance Rate Bar Chart, Forecast Line (Dt_Customer)
Advanced: Decomposition Tree, Response by Segment (100% stacked bar)

Superstore Dashboard
Data Source: Superstore Dataset
Key Pages & Visuals:
Sales Dashboard
KPIs: Total Sales, Profit, Avg. Discount, Profit Margin %
Visuals: Line Chart (Sales & Profit Over Time), Pareto Chart (Top Products), Map (Sales by State)

Shipping & Orders Analysis
Visuals: Histogram (Delivery Time), Bar (Orders by Region & Ship Mode)
Table: Top 10 Profitable Products (with icons), Funnel: Order → Ship → Delivery
